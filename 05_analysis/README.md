## Analytical Phases

The analytical work in this project is organized into multiple logical
phases. Each phase focuses on answering specific business questions
and builds on the results of the previous phase.

---

### Phase 1 – Data Validation
- Inspect database schema
- Validate data quality and integrity
- Identify data coverage and completeness issues

---

### Phase 2 – Time-Based Analysis
- Analyze order volume trends over time
- Apply time bucketing (daily, monthly patterns)

---

### Phase 3 – Regional Analysis
- Analyze state-level month-on-month order trends
- Calculate regional performance metrics

---

### Phase 4 – Revenue Analysis
- Calculate revenue metrics
- Assess economic impact and contribution

---

### Phase 5 – Delivery Performance Analysis
- Calculate delivery duration
- Analyze logistics efficiency and delays

---

### Phase 6 – Payment System Analysis
- Analyze month-on-month payment trends
- Evaluate payment method distribution
