## Dataset Overview

This project uses a Brazilian e-commerce dataset that represents
Target’s online retail operations.

### Time Period
- 2016 to 2018

### Approximate Size
- ~100,000 orders

---

## Tables Included

- customers          → Customer demographic information
- orders             → Order-level details and timestamps
- order_items        → Product-level details per order
- payments           → Payment type and installment information
- products           → Product attributes
- sellers            → Seller information
- reviews            → Customer reviews and ratings
- geolocation        → Geographic location details

---

## Notes
- All data is stored in raw CSV format
- No transformations are applied at this stage
- Data validation and quality checks are performed during analysis
